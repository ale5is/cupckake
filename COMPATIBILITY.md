# Compatibility target

The bundle targets native hook API **359** from Horizon revision
`6475f62f3c834b7489e1816bf47f47ea5eb2b879`. It targets Minecraft Java Edition **26.3**.

The native bundle is pinned to Horizon revision
`6475f62f3c834b7489e1816bf47f47ea5eb2b879` and horizon-mixins revision
`e59da9094f0c2fdda6c627fe9eff22dec6a906f0`.

The bundle uses the named hooks `world_lifecycle`, `net_from_server`,
`player_submit`, `input_key`, `command`, and `frame`. These hooks
and their version-1 signatures are present in the target Horizon revision.
